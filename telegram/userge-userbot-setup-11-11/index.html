Userge userbot setup

November 11, 2021

എങ്ങനെയാണ് നമ്മുടെ അക്കൗണ്ടിൽ ഒരു userbot ലിങ്ക് ചെയ്യുന്നത് എന്നു നോക്കാം...


[എന്താണ് യൂസർബോട്ട് എന്നറിയാനായി ഇവിടെ ക്ലിക്ക് ചെയ്യുക]


Userbot തയ്യാറാക്കുന്നത് പലരും കരുതുന്നതുപോലെ അത്ര ആനക്കാര്യം ഒന്നുമല്ല, basic knowledge ഉള്ള ആർക്കും വളരെയെളുപ്പത്തിൽ ചെയ്യാൻ കഴിയും.

Userbot ഉപയോഗിക്കുന്നത് safe ആണോ?
ഇത് ഉപയോഗിച്ചാൽ ടെലഗ്രാം അക്കൗണ്ട് ബാൻ ആവുമോ?

The popular userbot codes are open-source. അതിന്മേലും അതെഴുതിയ devs ന്മേലും ഉള്ള വിശ്വാസത്തിൽ ധൈര്യമായി use ചെയ്യാം.
നിങ്ങളായിട്ട് Telegram's terms of service violate ചെയ്യാത്തിടത്തോളം ബാൻ ഒന്നും കിട്ടില്ല.


IMPORTANT THING: Userbot കഴിവതും സ്വയം configure ചെയ്യുക. മറ്റൊരാളുടെ സഹായം തേടുമ്പോൾ ഒരിക്കലും login credentials പോലുള്ള confidential things ഷെയർ ചെയ്യാതിരിക്കുക.


അപ്പൊ കാര്യത്തിലേക്ക് കടക്കാം...
Userge userbot ആണ് നമ്മൾ setup ചെയ്യാൻ പോവുന്നത്.


Requirements:

• Heroku account
• API ID & API HASH
• BOT token
• Pyrogram SESSION STRING
• Database URL
• Log channel ID & your user ID


ഇത്രയും കാര്യങ്ങൾ ആദ്യം തന്നെ കോപ്പി ചെയ്തു സൂക്ഷിക്കുക.


1. API ID, API HASH, SESSION STRING, BOT TOKEN എന്നിവ എങ്ങനെയാണ് collect ചെയ്യുന്നത് എന്ന് ഈ article നോക്കി മനസ്സിലാക്കുക.

(SESSION STRING എടുക്കാൻ മുകളിലുള്ള method ബുദ്ധിമുട്ട് ഉണ്ടെങ്കിൽ try these alternative methods)


2. Database url എടുക്കാനായി ഈ tutorial video കാണുക.


3. ഒരു private ചാനൽ ഉണ്ടാക്കി അതിന്റെ ID കോപ്പി ചെയ്തു സൂക്ഷിക്കുക. (Example: -1001371274651) ID എടുക്കാനായി ആ ചാനലിലെ ഏതെങ്കിലും ഒരു മെസ്സേജ് @MissRose_bot ലേക്ക് forward ചെയ്തിട്ട് /id എന്ന് reply കൊടുത്താൽ മതി.


4. ചാനലിലേക്ക് നേരത്തേ ഉണ്ടാക്കിയ ബോട്ടിനെ admin ആയി add ചെയ്യുക.


ഇനി Heroku ലേക്ക് deploy ചെയ്യാം...


https://heroku.com/deploy?template=https://github.com/Jigarvarma2005/HelperScript-V2


ഈ ലിങ്കിൽ ക്ലിക്ക് ചെയ്തു വരുന്ന പേജിൽ, നമ്മൾ നേരത്തെ collect ചെയ്തുവെച്ച variables ഓരോന്നായി fill ചെയ്ത് deploy അമർത്തുക.


Deploy successful ആയതിനു ശേഷം manage apps എടുത്ത് worker mode ഓണാക്കിയാൽ userbot work ചെയ്തു തുടങ്ങും. Worker mode toggle ചെയ്യുന്നതിനെപ്പറ്റിയും മുകളിൽ പറഞ്ഞ article ൽ പറഞ്ഞിട്ടുണ്ട്.
(Bot running ആണെന്ന് ഉറപ്പു വരുത്താനായി ഏതെങ്കിലും ചാറ്റിൽ .ping എന്ന് മെസ്സേജ് അയച്ചു നോക്കുക)


Basic ഫീച്ചറുകളോടു കൂടി userge userbot റെഡിയായിട്ടുണ്ട്. ഏതെങ്കിലും ചാറ്റിൽ .help എന്ന് മെസ്സേജ് അയച്ചാൽ available ആയിട്ടുള്ള commands കാണാൻ കഴിയും.


Full power ൽ കൂടുതൽ കാര്യങ്ങൾ explore ചെയ്യാൻ (Gdrive etc) opional ആയിട്ടുള്ള variables പിന്നീട് Heroku config vars ൽ ഓരോന്നായി add ചെയ്യാവുന്നതാണ്.

ഉദാഹരണത്തിന്:

KEY: CUSTOM_PLUGINS_REPO
VALUE: https://github.com/UsergeTeam/Userge-Plugins


ഇങ്ങനെ add ചെയ്താൽ ആ repository ൽ ഉള്ള അത്രയും features (plugins) userbot ൽ add ആവും.
• List of other optional variables you can add later on Heroku config. vars.

HEROKU_APP_NAME, HEROKU_API_KEY എന്നീ variables (vars) ഇങ്ങനെ set ചെയ്താൽ പിന്നെ ബാക്കിയുള്ള variables ടെലഗ്രാമിൽ നിന്നു തന്നെ കമാൻഡ് വഴി remotely add ചെയ്യാൻ കഴിയും.
(ഉദാ: .setvar PLUGINS_CHAT_ID -1001371274651)


Assistance ന് @UsergeOT ഗ്രൂപ്പിൽ join ചെയ്യുക.


Finally... How to opt out of userbot?
പിന്നീട് വേണ്ടെന്ന് തോന്നിയാൽ userbot എങ്ങനെ ഒഴിവാക്കാം?
Simple. Go to Settings > Devices
& then terminate the 'Pyrogram session' 😇🤙
