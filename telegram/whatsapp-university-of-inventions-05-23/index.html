WhatsApp university of inventions

May 23, 2023

വാട്സാപ്പിൽ എന്ത് ഫീച്ചർ വന്നാലും ടെലഗ്രാമിനെ കോപ്പിയടിച്ചു എന്നുള്ള കമന്റ് കാണാറുണ്ട്.

Let's take a list...

താഴെ കാണുന്ന ഫീച്ചറുകൾ എല്ലാം ടെലഗ്രാമിൽ വന്നതിന് ശേഷം വർഷങ്ങൾ കഴിഞ്ഞ് വാട്സാപ്പിൽ വന്നവയാണ്.

(എല്ലാത്തിന്റെയും patent ടെലഗ്രാമിന് ആണെന്നല്ല. പക്ഷേ പലതും ഈച്ചക്കോപ്പിയാണ്)


Stickers
സ്റ്റിക്കറുകളും സ്റ്റിക്കർ പാക്കുകളും.
ടെലഗ്രാമിലെ t.me/addsticker പോലെ വാട്സാപ്പിൽ wa.me/addsticker ആക്കിയത്.


Swipe to lock voice recording
കുറച്ചു നാൾ മുന്നേ വരെ വോയ്‌സ് റെക്കോർഡ് ചെയ്യാൻ ഞെക്കി പിടിക്കണമായിരുന്നു. ഇപ്പോളുള്ള ബട്ടൺ swipe ചെയ്ത് recording ലോക്ക് ചെയ്യുന്ന സൗകര്യം.


YouTube playback in app PiP
യൂട്യൂബ് link ക്ലിക്ക് ചെയ്താൽ WhatsApp ൽ തന്നെ picture-in-picture ആയി കാണാൻ കഴിയുന്നത്.


Mentioning users in group
@ ടൈപ്പ് ചെയ്ത് ഗ്രൂപ്പിൽ മെംബേർസിനെ മെൻഷൻ ചെയ്യുന്നത്.


Mention counter
ഗ്രൂപ്പിൽ നമ്മളെ ആരെങ്കിലും മെൻഷൻ ചെയ്താൽ main സ്ക്രീനിലും chat സ്ക്രീനിലും count കാണിക്കുന്നത്.


Replies by selecting specific messages
മെസേജിന് റിപ്ലൈ ചെയ്യുന്ന സൗകര്യം. മുമ്പ് മെസ്സേജ് അയക്കൽ മാത്രം ആയിരുന്നു. ഏത് മെസ്സേജിനുള്ള റിപ്ലൈ ആണെന്ന് ഊഹിച്ചു കണ്ടുപിടിക്കേണ്ടിയിരുന്നു.


Swipe to reply
മെസ്സേജിൽ swipe ചെയ്ത് റിപ്ലൈ ചെയ്യാനുള്ള സൗകര്യം. മുന്നേ മെസ്സേജിൽ ഞെക്കി പിടിച്ച് സ്ക്രീനിന്റെ മുകളിലെ റിപ്ലൈ ബട്ടൺ സെലക്ട് ചെയ്യണമായിരുന്നു.


Pinned chats
മെയിൻ സ്‌ക്രീനിൽ ചാറ്റുകൾ priority അനുസരിച്ചു pin ചെയ്തിടാനുള്ള സൗകര്യം.


Dual verification
2 step വെരിഫിക്കേഷൻ.


Gif search
Gif സേർച്ച്‌ ചെയ്തെടുത്ത് അയക്കാനുള്ള സൗകര്യം.


Web image search
ഗ്രൂപ്പിന് dp ഇടുമ്പോൾ വെബ്ബിൽ നിന്ന് സെർച്ച് ചെയ്തെടുക്കാനുള്ള സൗകര്യം.


Text formatting
Bold, italic, strike, underscore എന്നിങ്ങനെ text format ചെയ്ത് അയക്കാൻ കഴിയുന്നത്. ഇനി mono, spoiler ഒക്കെ വന്നേക്കാം.


Forwarded labels
ഫോർവേഡ് ചെയ്യപ്പെട്ട മെസ്സേജ് ആണെങ്കിൽ forwarded എന്ന് മുകളിൽ കാണിക്കുന്നത്.
ഭാവിയിൽ ടെലഗ്രാമിലെ പോലെ അയച്ച ആളുടെ പേരും കണ്ടേക്കാം.


Pdf support
Pdf ഉൾപ്പെടെയുള്ള documents അയക്കാൻ കഴിയുന്നത്.


Profile picture privacy
നമ്മുടെ dp ആർക്കൊക്കെ കാണാം എന്ന് തീരുമാനിക്കാൻ കഴിയുന്നത്.


Downloading percentage
Documents ഒക്കെ ഡൌൺലോഡ് ചെയ്യുമ്പോ ശതമാനം കാണിക്കുന്നത്. മുന്നേ റൗണ്ട് നോക്കി ഊഹിച്ച് അറിയണമായിരുന്നു.


Group info / description text
ഗ്രൂപ്പിന്റെ info text ഉം ഗ്രൂപ്പ് description ഉം ഒക്കെ ഈയടുത്താണ് വന്നത്.


Group joining links & manage links
Add member മാത്രം ഉണ്ടായിരുന്ന ഇടത്ത് ഇപ്പോൾ invite links ഒക്കെ ഉണ്ട്.


Revoke messages
കൈ വിട്ട കല്ല് പോലെ ആയിരുന്ന വാട്സാപ്പിൽ ഈയടുത്താണ് അയച്ച മെസ്സേജ് delete ചെയ്യാനുള്ള സൗകര്യം വന്നത്.


Admin only messaging in groups
അഡ്മിന് മാത്രം മെസ്സേജ് അയക്കാൻ കഴിയുന്ന ഗ്രൂപ്പുകൾ.


Chat filters - unread, contacts, non contacts എന്നിങ്ങനെ മെസ്സേജുകൾ തരംതിരിച്ച് സെർച്ച് ചെയ്യാൻ കഴിയുന്നത്.


Self destructive messages
View once messages. പിന്നെയും ഒരു വർഷം കഴിഞ്ഞാണ് ഇതിന് സ്ക്രീൻഷോട്ട് പ്രൊട്ടക്ഷൻ വേണമെന്ന് അവർക്ക് തോന്നുന്നത്.


Playback speed adjustment for voice notes
വേഗത കൂട്ടി വോയിസ് മെസ്സേജുകൾ കേൾക്കാൻ കഴിയുന്നത്.


Background playback for audio files
വോയിസ് മെസ്സേജുകൾ കേൾക്കുന്നതിനിടയ്ക്ക് ഒരു ചാറ്റിൽ നിന്ന് back പോയാൽ മുന്നേ സ്റ്റോപ്പ് ആകുമായിരുന്നു. ഇപ്പൊ ബാക്ക്ഗ്രൗണ്ട് പ്ലേബാക്ക് ഉണ്ട്.


Wave seekbar in voice notes
തിരമാല ആകൃതിയിലുള്ള seekbar


Message reactions & reaction list
മെസ്സേജുകൾ ഞെക്കിപ്പിടിച്ച് റിയാക്ട് ചെയ്യാൻ കഴിയുന്നത്. Double tap ചെയ്ത് quick react ചെയ്യാനുള്ള ഫീച്ചർ ഉടനെ വരും.


File sharing upto 2GB
ഇപ്പോളും videos ന്റെ മാക്സിമം 100MB ആണ്.


Admin privilege to delete group messages
ഗ്രൂപ്പിൽ വന്ന മെസ്സേജ് അഡ്മിന് ഡിലീറ്റ് ചെയ്യാനുള്ള അധികാരം. മുന്നേ spam, scam ഒക്കെ വരുമ്പോ അഡ്മിൻ അടക്കം നോക്കുകുത്തിയ പോലെ നോക്കിയിരിക്കണമായിരുന്നു.


Participants profile pictures in groups
ഗ്രൂപ്പിൽ മെസ്സേജിന് അടുത്തായി അയച്ച ആളുടെ ഡിപി കാണിക്കുന്നത്.


Saved messages (Own chat)
പ്രധാനപ്പെട്ട മെസ്സേജുകൾ സേവ് ചെയ്തിടാൻ സ്വന്തം ചാറ്റ്.


Group polls
അഭിപ്രായ സർവേ. Quiz mode ഉടനെ പ്രതീക്ഷിക്കാം.


Approve new member requests
മെമ്പർഷിപ്പ് അപ്പ്രൂവൽ.


Edit messages
മെസ്സേജുകൾ എഡിറ്റ് ചെയ്യാനുള്ള സൗകര്യം. ബേസിക് ഫീച്ചറാണ്. വന്നത് 2023 ലും.


New message menu
മെസ്സേജ് ഡിലീറ്റ് ചെയ്യാനോക്കെ അതിൽ ഞെക്കി പിടിച്ചിട്ട് സ്ക്രീനിന്റെ മുകളിലെ ഓപ്ഷൻസിൽ നിന്ന് choose ചെയ്യണമായിരുന്നു. ഇനി മെസ്സേജിന് അടുത്തുതന്നെ മെനു വരും.


Channels & usernames
യൂസർനെയിം ഉള്ള പബ്ലിക് ചാനലുകൾ.


Semi-transparent navigation bar
Scroll ചെയ്യുന്നതിന് അനുസരിച്ച് ഭാഗികമായി ചാറ്റിലെ നിറങ്ങളെ കാണിക്കുന്ന navigation bar.


Screen sharing
Video call നിടക്ക് screen ലെ contents share ചെയ്യാൻ കഴിയുന്ന ഫീച്ചർ.
