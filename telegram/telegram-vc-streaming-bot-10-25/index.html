Telegram VC streaming bot

October 25, 2021
Special thanks to SubinPS for the source code of VC streaming bot

ടെലഗ്രാമിലെ പല ചാനലുകളിലും ലൈവ് ആയി ക്രിക്കറ്റും ഫുട്ബോളും വാർത്താ ചാനലുകളും റേഡിയോ സ്റ്റേഷനുകളും ഒക്കെ stream ചെയ്തു കണ്ടിട്ടില്ലേ?

ഒരു ടെലഗ്രാം ബോട്ടിന്റെയും അതുമായി ലിങ്ക് ചെയ്ത ഒരു ടെലഗ്രാം അക്കൗണ്ടിന്റെയും സഹായത്തോടെയാണ് ഇത് ചെയ്യുന്നത്.


നമുക്ക് നമ്മുടെ ഗ്രൂപ്പിലോ ചാനലിനോ വേണ്ടി ഇങ്ങനെ video / audio play ചെയ്യിക്കാനായി സ്വന്തമായി ഒരു ബോട്ട് എങ്ങനെ ഉണ്ടാക്കാം എന്നു നോക്കാം...


Main requirements:

• ഒരു ടെലഗ്രാം bot
• Stream ചെയ്യാനായി ഒരു TG അക്കൗണ്ട്
• Heroku അക്കൗണ്ട്


1. ആദ്യമായി @Botfather വഴി ഒരു ടെലഗ്രാം ബോട്ട് ഉണ്ടാക്കി അതിൽ നിന്നും കിട്ടുന്ന BOT TOKEN copy ചെയ്തു വെക്കുക.

Screenshot:


2. Stream ചെയ്യാൻ ഉദ്ദേശിക്കുന്ന ടെലഗ്രാം അക്കൗണ്ടിൽ നിന്നും my.telegram.org ൽ login ചെയ്ത് API development tools ൽ നിന്നും API ID യും API HASH ഉം കോപ്പി ചെയ്തു സൂക്ഷിക്കുക.

Screenshot:


3. ഇനി, https://repl.it/@subinps/getStringName

ഈ ലിങ്ക് തുറന്ന് വരുന്ന വിൻഡോയിൽ മുകളിൽ പറഞ്ഞ API ID യും API HASH ഉം stream അക്കൗണ്ടിന്റെ ഫോൺ നമ്പറും ഒക്കെ ഓരോന്നായി കൊടുത്ത് login ചെയ്ത് session string എടുക്കുക.

Screenshot:

ഇങ്ങനെ കിട്ടുന്ന Session string ആ അക്കൗണ്ടിലെ saved messages ലേക്കാണ് വരുന്നത്. അതും copy ചെയ്തു സൂക്ഷിക്കുക. (Do not share with anyone)

4. Heroku ൽ sign up ചെയ്യുക.
Link: https://signup.heroku.com/login

Screenshot:


5. ഇനി ടെലഗ്രാം ആപ്പ് തുറന്ന് stream ചെയ്യാൻ ഉദ്ദേശിക്കുന്ന ഗ്രൂപ്പ് / ചാനലിലേക്ക് streamer അക്കൗണ്ടും streamer ബോട്ടും add ചെയ്ത് admin പെർമിഷൻസ് (manage voice chats) നൽകുക.

ആ ഗ്രൂപ്പിന്റെ / ചാനലിന്റെ ID കൂടി കണ്ടുപിടിച്ച് കോപ്പി ചെയ്തു വെക്കുക.
(Example: -1001092696260)


6. DATABASE_URI: MongoDB database url എടുക്കുന്നത് എങ്ങനെ എന്നറിയാൻ ഈ tutorial വീഡിയോ കാണുക. (Optional)

അവസാനമായി ബോട്ട് Heroku ലേക്ക് deploy ചെയ്യുന്ന step ആണ്...

അതിന് ഈ ലിങ്കിൽ ക്ലിക്ക് ചെയ്യുക: https://heroku.com/deploy?template=https://github.com/subinps/VCPlayerBot

ശേഷം വരുന്ന പേജിലെ required എന്നുള്ള variables എല്ലാം fill ചെയ്ത് താഴെയുള്ള deploy ബട്ടൺ അമർത്തുക.
(required variables 7 എണ്ണം നമ്മൾ മുകളിൽ ഓരോന്നായി കോപ്പി ചെയ്ത് വെച്ചിട്ടുണ്ട്.)

Screenshot:

App deploy ആയതിനു ശേഷം manage app എടുത്ത് dyno type toggle ചെയ്താൽ ചാനലിൽ / ഗ്രൂപ്പിൽ voice ചാറ്റ് തുടങ്ങുന്നത് കാണാം.

ഇനി ബോട്ട് തുറന്ന് start കൊടുത്താൽ ബാക്കി കാര്യങ്ങൾ ഒക്കെ അതിൽ configure ചെയ്യാം.

Video / audio ഫയലോ യൂട്യൂബ് ലിങ്കോ ബോട്ടിലേക്ക് അയച്ചു കൊടുത്തിട്ട് അതിന് റിപ്ലൈ ആയി /play എന്നയച്ചാൽ VC യിൽ ആ ഫയൽ / ലിങ്ക് play ആവും.

Happy Telegraming 🤙
