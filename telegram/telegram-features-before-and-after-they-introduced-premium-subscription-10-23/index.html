Telegram features - പ്രീമിയം വരുന്നതിന് മുമ്പും ശേഷവും

October 23, 2023

ജൂലൈയിൽ, stories ഫീച്ചർ എത്തുന്നതിനെപ്പറ്റിയുള്ള rumors കേട്ടതുമുതൽ ഒരു Telegram fan എന്നനിലയിൽ വളരെയധികം excitement ഓടെയാണ് അതിന്റെ വരവിനെ പ്രതീക്ഷിച്ചിരുന്നത്.


ഒരുപക്ഷേ August ൽ പത്താം പിറന്നാളിന് Telegram, stories for everyone ആക്കി അവതരിപ്പിച്ചിരുന്നു എങ്കിൽ അന്നത്തെ hype വെച്ച് അത് use ചെയ്തു തുടങ്ങി ശീലം ആവുമായിരുന്ന ഒരു വലിയ കമ്യൂണിറ്റി ഇവിടെ ഉണ്ടായേക്കുമായിരുന്നു.


Stories, replies, conversation!
ഇത് ടെലഗ്രാം പോലെയൊരു instant messenger ന്റെ വളർച്ചയെ നല്ലതുപോലെ help ചെയ്യുമായിരുന്നു.


എന്നാലിപ്പോ ചൂടാറിയ ചായയുടെ അവസ്ഥയിലാണ് tg stories. വന്ന് മൂന്നു മാസത്തോളം കഴിഞ്ഞിട്ടും premium only ആയി തുടരുന്നു. Everyone ആയാലും ആദ്യത്തെ hype ൽ ഉണ്ടാവുമായിരുന്ന അത്രയും പേര് ഇനി ഇതിന്റെ ഭാഗമാവില്ലെന്ന് ഉറപ്പാണ്. Telegram ചെയ്ത വലിയൊരു മണ്ടത്തരമായാണ് എനിക്ക് ഇതിനെ തോന്നുന്നത്. Limit വെച്ച്, one story per day ആക്കിയെങ്കിലും എല്ലാവർക്കും കൊടുക്കണമായിരുന്നു.


2022 നു ശേഷം വരുന്ന പുതിയ features ന്റെ കാര്യവും വ്യത്യസ്തമല്ല, most of them are premium only. പഴയതുപോലെ new updates നായി Telegram ആരാധകർ നോക്കിയിരിക്കുന്ന കാലം ഇനി ഉണ്ടായേക്കില്ല, unless we're spending a lot to be a part of this overpriced subscription stuff.


Custom profile picture ഒക്കെ നേരത്തെ വന്നത് നന്നായി. ഇപ്പൊ ആയിരുന്നെങ്കിൽ ഉറപ്പായും durov അത് പ്രീമിയം only ആക്കി ഇറക്കിയേനെ.
(ഇതിന് മുന്നേ വന്ന voice video chat ഉൾപ്പെടെയുള്ള കിടു features എല്ലാം ഇന്നായിരുന്നെകിൽ premium only ആക്കിയേനെ.) 💯


CEO സർ സ്വന്തം ചാനലിലെ reactions ഉം പിന്നാലെ comments ഉം ഒഴിവാക്കിയത് തന്നെ വലിയൊരു സൂചന ആയിരുന്നു എന്നുവേണം കരുതാൻ 🤟😁


Screenshot ൽ ഉള്ളത് name colour change ചെയ്യാൻ പറ്റുന്ന latest beta ഫീച്ചർ which is also premium only.
