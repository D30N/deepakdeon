Telegram groups

May 7, 2021

ഫേസ്ബുക്കിലെ അയ്യായിരവും പതിനായിരവും ഒക്കെ മെംബേർസ് ഉള്ള ഗ്രൂപ്പുകളിൽ പോസ്റ്റുകളായും കമന്റുകളായും കാണാറുള്ള ചോദ്യമാണ് "ഈ ഗ്രൂപ്പിന് വാട്സാപ്പ് ഗ്രൂപ്പ് ഉണ്ടോ?" എന്ന്.


ചില facebook കമ്യൂണിറ്റികൾക്ക് ഒക്കെ വാട്സാപ്പ് ഗ്രൂപ്പ് ഉണ്ട്താനും. ഈ അഞ്ഞൂറും അറുന്നൂറും പേരെ നാലോ അഞ്ചോ വാട്സാപ്പ് ഗ്രൂപ്പുകളിൽ ആക്കി ഇവർ എങ്ങനെയാണ് അതൊക്കെ മാനേജ് ചെയ്യുന്നത് എന്ന് ആലോചിക്കാറുണ്ട്. (വെവ്വേറേ റൂമുകളിൽ ഇരുന്നു പൊതുയോഗം കൂടുന്ന പോലെ)


ടെലിഗ്രാമിലേക്ക് വരുമ്പോൾ ഇത്തരം കൂട്ടായ്മകൾക്ക് കിട്ടുന്ന വലിയൊരു പ്രിവിലേജാണ് അതിലെ ഗ്രൂപ്പുകൾ.


1. ആദ്യം ടെലിഗ്രാം ഗ്രൂപ്പുകളുടെ ചില പ്രത്യേകതകൾ നോക്കാം... (for beginners)


• അയ്യായിരവും പതിനായിരവും മെംബേർസ് ഉള്ള ഗ്രൂപ്പുകൾ ടെലിഗ്രാമിലെ സാധാരണ കാഴ്ചയാണ്. (രണ്ടു ലക്ഷം പേർക്ക് വരെ join ചെയ്യാം.)


• ഇത്രയും പേർ അംഗങ്ങൾ ആയിട്ട് ഉള്ളപ്പോ ഒരേ സമയം ഒരുപാട് മെസ്സേജുകൾ വരുന്നത് സ്വാഭാവികം, പക്ഷേ ആയിരക്കണക്കിന് മെസ്സേജുകൾ ഒരുമിച്ചു വന്നാലും ഫോണോ ടെലിഗ്രാം ആപ്പോ ഹാങ്ങ്‌ ആവില്ല. (Telegram cloud based IM ആയതിനാലാണിത്)


• ടെലിഗ്രാമിന്റെ settings ൽ notifications എന്നുള്ളത് groups ന് ഓഫാക്കി ഇട്ടാൽ ഇങ്ങനെ എപ്പോളും വരുന്ന മെസ്സേജുകൾ നോട്ടിഫിക്കേഷൻ ആയിട്ട് ശല്യം ആവില്ല. ആവശ്യമുള്ള ഗ്രൂപ്പുകൾ exclude ചെയ്യാനും സാധിക്കും.


• വലിയൊരു പബ്ലിക് ഗ്രൂപ്പിൽ join ചെയ്യുമ്പോൾ നമ്മുടെ ഫോൺ നമ്പർ മറ്റ് അംഗങ്ങൾക്ക് കാണാൻ കഴിയില്ലേ എന്നൊരു സംശയം ഉണ്ടാവാം. ടെലിഗ്രാമിലെ ഫോൺ നമ്പർ പ്രൈവസി by default 'contacts only' ആയിരിക്കും. അതായത് നമ്മുടെ നമ്പർ നമ്മുടെ contacts ൽ ഉള്ളവർക്ക് അല്ലാതെ മറ്റാർക്കും കാണാൻ പറ്റില്ല.


• ടെലിഗ്രാമിലെ മറ്റ് ചാറ്റുകളിൽ ഉള്ളത് പോലെ തന്നെ നമ്മൾ അയച്ച മെസ്സേജ് എഡിറ്റ് ചെയ്യാനും ഡിലീറ്റ് ചെയ്യാനും ഒക്കെ ഗ്രൂപ്പിലും കഴിയും.


• വലിയ ഗ്രൂപ്പുകളിൽ ഒരുപാട് അംഗങ്ങൾ വെവ്വേറെ കാര്യങ്ങൾ ചർച്ച ചെയ്യുമ്പോൾ മെസ്സേജുകൾ കുഴഞ്ഞു മറിഞ്ഞു കിടക്കുന്നത് ഏതൊരു messenger ലെയും ബുദ്ധിമുട്ട് ആണ്.

എന്നാൽ ടെലിഗ്രാമിൽ ഗ്രൂപ്പിലെ ഏതെങ്കിലും ഒരു മെസ്സേജിൽ ടാപ് ചെയ്താൽ view thread എന്നൊരു ഓപ്ഷൻ കാണിക്കും. അതിൽ ക്ലിക്ക് ചെയ്താൽ ആ മെസ്സേജിന് കിട്ടിയ മറുപടികൾ മാത്രമായി കാണാം.


• ടെലിഗ്രാം ഗ്രൂപ്പിൽ എന്തെങ്കിലും സേർച്ച്‌ ചെയ്യുമ്പോൾ നമുക്ക് date വെച്ചും user വെച്ചും സേർച്ച്‌ ചെയ്യാം. അതായത് india എന്ന് സേർച്ച്‌ ചെയ്യുമ്പോൾ user എന്നിടത്ത് deepak എന്നയാളെ തിരഞ്ഞെടുത്താൽ deepak എന്നയാൾ അയച്ച india എന്ന മെസ്സേജുകൾ മാത്രമായി കാണാം. അതുപോലെ തന്നെ ഒരു പ്രത്യേക തീയതി വെച്ച് ആ ദിവസത്തെ മെസ്സേജുകളിലേക്ക് പോകാം.


2. ഇനി ടെലിഗ്രാമിലെ അഡ്മിന് ഗ്രൂപ്പിനുമേൽ എന്തൊക്കെ അധികാരങ്ങളാണ് ഉള്ളതെന്ന് നോക്കാം...


ഒരു മെമ്പർ അബദ്ധത്തിൽ അയച്ച അനാവശ്യ മെസ്സേജ് ഒക്കെ ഒന്നു ഡിലീറ്റ് ചെയ്യാൻ പോലും കഴിയാതെ വട്ടം കൂടി വെറുതെ നോക്കി ഇരിക്കേണ്ടി വരുന്ന വാട്സാപ്പ് ഗ്രൂപ്പ് അഡ്മിൻസിനൊക്കെ ടെലിഗ്രാം സ്വർഗ്ഗമാണ്!


• ടെലിഗ്രാം ഗ്രൂപ്പിൽ വരുന്ന മെസ്സേജുകൾക്കുമേൽ അഡ്മിന് പൂർണ്ണ നിയന്ത്രണമാണുള്ളത്.

• ഏത് മെസ്സേജും അഡ്മിന് ഡിലീറ്റ് ചെയ്യാം. ഒരു മെമ്പർ എങ്ങനെയുള്ള മെസ്സേജ് അയക്കണം എന്ന് തീരുമാനിക്കാം...

• സ്റ്റിക്കർ അയച്ചു വെറുപ്പിക്കുന്ന ആളുകളെ sticker മാത്രമായി restrict ചെയ്യാം, വോയ്‌സ്, ലിങ്ക് ഒക്കെ ആണെങ്കിൽ അതും വിലക്കാം.

• തുടരെ മെസ്സേജ് അയച്ചു സ്പാം ചെയ്യുന്നവരെ മുഴുവനായി mute ചെയ്യാം, ban ചെയ്യാം.

• സ്റ്റിക്കറോ മീഡിയയോ ലിങ്കോ ഒന്നും ആവശ്യം ഇല്ലാത്ത ഗ്രൂപ്പ് ആണെങ്കിൽ message only ആക്കാം.

• പുതിയ admins നെ ചേർക്കുമ്പോൾ അവർക്ക് എന്തൊക്കെ അധികാരങ്ങൾ ഉണ്ടാവണം എന്ന് തീരുമാനിക്കാം.

• ഒരേസമയം ആയിരക്കണക്കിന് മെസ്സേജുകൾ ഒക്കെ വരുന്ന ഗ്രൂപ്പ് ആണെങ്കിൽ slow mode ഇടാം. (ഇത് 1min കൊടുത്താൽ മെമ്പറിന് ഒരു മിനിറ്റിൽ ഒരു മെസ്സേജ് മാത്രേ അയക്കാൻ പറ്റൂ.)

• പിന്നെ ഗ്രൂപ്പിന്റെ log പരിശോധിക്കാം, കഴിഞ്ഞ 48 മണിക്കൂറിനിടെ നടന്ന ആക്ടിവിറ്റികൾ അറിയാം. (Deleted messages, restrictions etc)

• ഗ്രൂപ്പിന്റെ statistics അറിയാം. കഴിഞ്ഞ ദിവസങ്ങളിൽ ഗ്രൂപ്പിൽ വന്ന മെസ്സേജുകളുടെ എണ്ണം, ഏറ്റവും കൂടുതൽ മെസ്സേജ് അയച്ച ആളുകൾ, ഏറ്റവും നന്നായി പണിയെടുത്ത അഡ്മിൻ അങ്ങനെ അങ്ങനെ...


പിന്നെ "മനുഷ്യൻ അല്ലേ പുള്ളേ..." ഏത് നേരവും ഗ്രൂപ്പും നോക്കിയിരിക്കാൻ പറ്റില്ലല്ലോ എന്നുള്ളവർക്ക് admin പണിക്ക് ബോട്ടിനെ നിർത്താം! (Group managing robots)


Group managing bots എന്തൊക്കെ ചെയ്യും എന്ന് നോക്കാം..

(@banhammermarie_bot @missrose_bot)


• പുതുതായി വരുന്ന അംഗത്തെ സ്വാഗതം ചെയ്യിക്കാം..


• നമ്മൾ കൊടുത്ത blacklisted വാക്കുകൾ മനസ്സിലാക്കി ആ മെസ്സേജുകൾ ഗ്രൂപ്പിൽ വരുമ്പോൾ ഓട്ടോമാറ്റിക്കായി ഡിലീറ്റ് ചെയ്യിക്കാം. വേണമെങ്കിൽ അയച്ച ആളെ mute / warn / ban ചെയ്യിക്കാം.


• ഒരു പ്രത്യേക keyword ന് നമ്മൾ reply set ചെയ്തു വെച്ചാൽ, മെമ്പർ ആ വാക്ക് അയക്കുമ്പോൾ bot മറുപടി കൊടുത്തോളും.


പറഞ്ഞു തുടങ്ങിയാൽ ഒരുപാടുണ്ട്...

@banhammermarie_bot ന്റെ കോഡ് ഓപ്പൺ സോഴ്സ് ആയതിനാൽ നമുക്ക് വേണമെങ്കിൽ അതിന്റെ ഒരു കോപ്പി bot, നമ്മുടെ ഗ്രൂപ്പിനു വേണ്ടി നമുക്ക് ഇഷ്ടമുള്ള പേരിൽ ഉണ്ടാക്കാം.
