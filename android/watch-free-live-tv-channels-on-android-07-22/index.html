Watch free live tv channels on android

July 22, 2022

ആൻഡ്രോയ്ഡ് ഫോണിലും ടീവിയിലും ഇനി ഫ്രീയായി ലൈവ് ടീവി ചാനലുകൾ കാണാം! Without ads. Including sports channels.


ആദ്യമായി ഫോണിൽ / ടീവിയിൽ TiviMate ആപ്പ് install ചെയ്യുക. Play store ൽ available ആണ്.
👉 https://play.google.com/store/apps/details?id=ar.tvplayer.tv (for TV)


👉 TiviMate official v4.4.apk (for phone)


👉 IPTVnator IPTV player (for pc)


ഫോണിൽ മാത്രം കാണാൻ ആണെങ്കിൽ OTT Navigator app ഉം ഉപയോഗിക്കാം...
ഇതിനെപ്പറ്റി പോസ്റ്റിന്റെ അവസാന ഭാഗത്ത്‌ എഴുതിയിട്ടുണ്ട്.


TiviMate & OTT Navigator ഇവ രണ്ടും IPTV (internet protocol television) players ആണ്. M3U, Xtream code, Stalker portal തുടങ്ങിയ playlists add ചെയ്താലാണ് ഇതിൽ TV ചാനലുകൾ കാണാൻ സാധിക്കുക.


TiviMate Configuration:


Install ആയതിനു ശേഷം app തുറന്ന് Use anyway, Add playlist എന്നീ ഓപ്‌ഷനുകൾ സെലക്ട്‌ ചെയ്യുക. (ഓരോന്നിലും double tap ചെയ്യേണ്ടിവരും.)




ഇനി Playlist type എന്നതിൽ M3U playlist സെലക്ട് ചെയ്ത് URL ചേർക്കണം.


മലയാളം ചാനലുകൾ കാണാൻ
https://iptv-org.github.io/iptv/languages/mal.m3u
ഈ ലിങ്ക് കോപ്പി ചെയ്ത് അതിൽ paste ചെയ്ത് done കൊടുക്കുക.

കൂടുതൽ m3u പ്ലേലിസ്റ്റുകൾക്ക്...

https://github.com/iptv-org/iptv


NB: Free വേർഷനിൽ ഒരു സമയം ഒരു playlist മാത്രമാണ് add ചെയ്യാൻ കഴിയുക. പുതിയ playlist ചേർക്കാൻ...
Settings > Playlist > Select > Delete playlist


ഈ രീതിയിൽ തന്നെ Stalker portal playlist ഉം ചേർക്കാവുന്നതാണ്...


Stalker portal playlist example:

Server address: http://mag.x-iptv.live/c/
Mac address: 00:1A:79:ac:4f:90

(ബാക്കി എല്ലാം empty ആക്കി ഇടുക)

Special thanks to @erenjeager00

OTT Navigator configuration:


Play store link: https://play.google.com/store/apps/details?id=studio.scillarium.ottnavigator


ഇതിൽ Stalker Portal Add ചെയ്യാൻ:
Settings > Add provider > Generic middleware server > Stalker portal
ഇങ്ങനെ സെലക്ട് ചെയ്ത് മുകളിലെ stalker portal url & mac address കൊടുക്കുക.
