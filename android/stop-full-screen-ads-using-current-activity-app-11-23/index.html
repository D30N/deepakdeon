Stop full screen ads using Current Activity app

November 23, 2021

വെബ്സൈറ്റുകൾ browse ചെയ്യുമ്പോളും മറ്റും വരുന്ന annoying ആയിട്ടുള്ള പരസ്യങ്ങൾ (pop-ups & redirects) AdGuard DNS ഉപയോഗിച്ച് ഒഴിവാക്കുന്നത് എങ്ങനെ എന്ന് നമ്മൾ വായിച്ചു.

ഇനി, ചില 3rd party ആപ്പുകൾ (adware) background ൽ പ്രവർത്തിച്ച് കാണിക്കുന്ന full screen ads എങ്ങനെ തടയാം എന്നു നോക്കാം...

സാധാരണ നമ്മൾ മറ്റേതെങ്കിലും app ഉപയോഗിക്കുന്ന സമയത്താവും ഇങ്ങനെ full screen ads വരുന്നത്. അതുകൊണ്ടുതന്നെ ഒരുപാട് apps ഉപയോഗിക്കുന്നവർക്ക് ഏത് ആപ്പ് ആണ് പരസ്യം വരാൻ കാരണം എന്ന് മനസ്സിലാക്കാനും കഴിഞ്ഞെന്നു വരില്ല.

അതിനായി, Google play store ൽ നിന്നും Current Activity എന്ന app install ചെയ്യുക.
Link (updated): Download Current Activity.apk

ഇനി, ഈ app തുറന്ന് ആവശ്യമായ പെർമിഷനുകൾ (display over other apps, usage stats) നൽകിയതിനു ശേഷം show floating window എന്നത് enable ചെയ്യുക.


ഇനി ഫോണിൽ full screen ads വരുമ്പോൾ മുകളിൽ പരസ്യം കാണിക്കുന്ന ആപ്പിന്റെ package name കാണാൻ കഴിയും.
Example: net.tsapps.appsales


ഈ package name അതേപോലെ google search ചെയ്താൽ ഏത് ആപ്പ് ആണ് പരസ്യം കാണിക്കുന്നത് എന്ന് കണ്ടുപിടിച്ച് അത് uninstall ചെയ്യാവുന്നതാണ്.

PS: Appsales ന്റെ പേര് ഒരു ഉദാഹരണത്തിന് കാണിച്ചതാണ്. അത് ഒരിക്കലും ഒരു annoying ads കാണിക്കുന്ന app അല്ല. [What is AppSales?]

Current Activity ൽ കാണിക്കുന്ന package name ഗൂഗിൾ സെർച്ച്‌ വഴി കണ്ടുപിടിക്കാൻ കഴിഞ്ഞില്ലെങ്കിൽ, ഫോണിലെ apps ലിസ്റ്റ് എടുത്ത് അതിൽ name ഇല്ലാത്ത ഏതെങ്കിലും 3rd party app ഉണ്ടോ എന്നു നോക്കി അത് uninstall ചെയ്യുക.
