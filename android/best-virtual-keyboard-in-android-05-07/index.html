Best virtual keyboard in Android

May 7, 2021


ആൻഡ്രോയിഡിലെ best കീബോർഡ് ഏതാണ്???

ഏറ്റവും കൂടുതൽ ആളുകൾ ഉപയോഗിക്കുന്ന

• Gboard അഥവാ Google Keyboard

• SwiftKey അഥവാ Microsoft Swift Keyboard

• Google Indic Keyboard

• Manglish Keyboard


ഈ 4 ആപ്പുകൾ ഒന്നു നോക്കാം...

(Customisation / തീമിങ് - ന് മാത്രം പ്രാധാന്യം കൊടുക്കുന്ന കൊറേ കീബോർഡുകളും, മുകളിൽ പറഞ്ഞവയുടെ clone എന്ന് തോന്നിയ കുറച്ചു കീബോർഡുകളും ഒഴിവാക്കിയിട്ടുണ്ട്.)


നമ്മുടെ ടൈപ്പിങ്ങിനെ English typing, മലയാളം ടൈപ്പിംഗ്, Manglish typing എന്നിങ്ങനെ മൂന്നായി തിരിക്കാം.


• English type ചെയ്യാൻ 4 keyboards ഉം ഒരുപോലെ നല്ലതാണ്. So, ഇതിനായി മാത്രം പ്രത്യേകം കീബോർഡ് ഒന്നും ആവശ്യമില്ല.


• Manglish type ചെയ്യാൻ Gboard & SwiftKey ആണ് മികച്ചത്.


ഇംഗ്ലീഷ് വാക്കുകളെ പോലെയല്ല, മംഗ്ലീഷിൽ ഒരേ വാക്കുകൾ പലരും പല രീതിയിൽ ആണ് എഴുതുന്നത്.

ഉദാഹരണത്തിന് "എന്തൊക്കെയുണ്ട്" എന്നത് Enthokkeyund, Nthokkend, Enthokkend, Nthokkeyund, Enthokke undu എന്നിങ്ങനെയൊക്കെ എഴുതാം.


മലയാളത്തിലെ ഓരോ വാക്കുകളും ഇതുപോലെയാണ്. അതുകൊണ്ട് തന്നെ ഒരു തവണ ടൈപ്പ് ചെയ്യുമ്പോൾ tap ചെയ്തോ മറ്റോ personal dictionary ലേക്ക് ഈ വാക്കുകൾ add ചെയ്യുന്ന രീതിയിൽ ആണ് Gboard ഉം SwiftKey ഉം Manglish keyboard ഉം ഒക്കെ design ചെയ്തിട്ടുള്ളത്.


ഇങ്ങനെ സേവ് ആക്കിയ personal വാക്കുകൾ predict ചെയ്തു തരുന്നതിൽ Swiftkey തന്നെയാണ് best.


ഉദാ:

Nee chaya kudicho

Nee evide poyatha


ഈ രണ്ടു വാചകങ്ങൾ ചാറ്റിലോ മറ്റോ ഒന്നിലധികം തവണ ഉപയോഗിച്ചിട്ടുള്ളവർ ആണെങ്കിൽ Swiftkey ൽ Nee എന്ന് ടൈപ്പ് ചെയ്യുമ്പോൾ തന്നെ chaya എന്നും evide എന്നും മുകളിൽ suggestion കാണിക്കും. ചുമ്മാ tap ചെയ്ത് വിട്ടാൽ മതി.


(Manglish Keyboard ൽ ഒക്കെ ഈ suggestion വരണം എങ്കിൽ അടുത്ത വാക്കിന്റെ ആദ്യത്തെ അക്ഷരം കൂടി ടൈപ്പ് ചെയ്യണം)


ഇതിൽ Clipboard shortcut ഉള്ളതും വലിയൊരു സൗകര്യമാണ്. അതായത് ചെറിയ ഒരു പാരഗ്രാഫോ മറ്റോ ഒന്നിലധികം തവണ ഉപയോഗിക്കേണ്ടി വരുമ്പോ അത് ക്ലിപ് ബോർഡിൽ ആക്കി അതിന് ഒരു keyword കൊടുത്താൽ പിന്നെ ആ keyword ടൈപ്പ് ചെയ്യുമ്പോ ആ പാരഗ്രാഫ് മുഴുവനും suggestion വരും. ഒറ്റ ടാപ്പിൽ paste ചെയ്യാം.


ഇങ്ങനെ നമ്മുടെ Address ന് address എന്നും Mail ID ക്ക് mail എന്നും ഒക്കെ shortcut ഇടാം.


• മലയാളം ടൈപ്പ് ചെയ്യാൻ ആണെങ്കിൽ Manglish കീബോർഡ് ആണ് better.

(Google Indic കിടുവാണ് പക്ഷെ Key Border ഇല്ലാത്തത് വലിയ പോരായ്മയാണ്. മാത്രമല്ല അതിലെ മുകളിലെ നമ്പർ row ഒഴിവാക്കാനുള്ള ഓപ്ഷനും ഇല്ല.)


മംഗ്ലീഷ് കീബോർഡിലെ മലയാളം വോയ്‌സ് ടൈപ്പിംഗ് വളരെ accurate ആണ്.


ഗൂഗിൾ വോയ്‌സ് ടൈപ്പിംഗിൽ ഒക്കെ നമ്മൾ പറയുന്ന വാക്കുകളിൽ ചിലത് തെറ്റായി predict ചെയ്യാറുണ്ട്. ഇത് നമ്മൾ manual ആയിട്ട് തിരുത്തേണ്ടി വരും. എന്നാൽ മംഗ്ലീഷ് കീബോർഡിൽ ഇങ്ങനെ സംശയമുള്ള വാക്കുകൾ മഞ്ഞ നിറത്തിൽ വരികയും അതിൽ tap ചെയ്താൽ സമാനമായ വാക്കുകൾ കാണാൻ കഴിയുകയും അതിൽ touch ചെയ്ത് simple ആയി replace ചെയ്യാനും കഴിയും.


മംഗ്ലീഷ് കീബോർഡിൽ കഴിഞ്ഞ 2 വർഷത്തിനിടയിൽ UI അടക്കം നല്ല improvements ഉണ്ടായിട്ടുണ്ട്. Next word prediction + Personal dictionary cloud storage കൂടി ആക്കിയാൽ Manglish ടൈപ്പിങ്ങിനും Manglish Keyboard best ആവും.


പിന്നെ ഇപ്പോളും Handwriting input ഭയങ്കര ഈസി ആണെന്ന് പറയുന്ന ആൾക്കാരും ഉണ്ട് 🤣


'അമ്മ' എന്ന് എഴുതാൻ നമ്മളൊക്കെ A-m-m-a എന്ന് നാല് tap ചെയ്യുമ്പോ, handwriting fans സ്‌ക്രീനിൽ ചിത്രം വരച്ചു കഴിഞ്ഞിട്ടുണ്ടാവില്ല എന്നതാണ് സത്യം.
