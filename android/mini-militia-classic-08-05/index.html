Mini Militia Classic

August 5, 2021

Mini Militia : Doodle Army 2


ഓഫ്‌ലൈനായി ഫ്രണ്ട്സിന്റെ കൂടെ ഇത്രയും എൻജോയ് ചെയ്തു കളിച്ചൊരു 2D മൾട്ടി പ്ലേയർ ഗെയിം വേറെ ഉണ്ടായിട്ടില്ല. ❤️

16 പേർ 🔥
ഇപ്പോളും ഇത്രയും പേർക്ക് ഒരുമിച്ചു കളിക്കാൻ പറ്റിയ 60MB യിൽ താഴെയുള്ള action game ആൻഡ്രോയ്ഡിൽ വേറെ ഉണ്ടോ എന്നു തന്നെ സംശയമാണ്.

8 vs 8 ടീം. Yellow vs Blue.
ആറര മിനിറ്റ്. പലതവണ മരിച്ചും അഞ്ചു സെക്കന്റിൽ ഉയിർത്തെണീറ്റും അങ്ങനെ Outpost ന്റെയും Catacombs ന്റെയും Hightower ന്റെയും ഒക്കെ മായാ ലോകത്ത് "ട്ടോ ട്ടോ" ന്ന് ബഹളം വച്ചു പറന്നിരുന്ന കാലം.

ഇടി വെട്ടിയ പോലെയാണ് 2019 ഡിസംബറിൽ Appsomaniacs ന്റെ Mini Militia യെ Miniclips ഏറ്റെടുത്ത് 5.0 എന്ന ആപ്പ് ഇന്റർഫേസ് അടിമുടി മാറ്റിയ updation തരുന്നത്.

ഒറ്റ നോട്ടത്തിൽ കിടു എന്ന് തോന്നി എങ്കിലും...
ഒരുമിച്ചു കളിക്കാൻ offline mode തപ്പിയപ്പോളാണ് പണി പാളി എന്നു മനസ്സിലായത്. 🥺
LAN Wi-Fi ഓപ്ഷൻ എടുത്തു മാറ്റിയിരിക്കുന്നു.

എനിക്കുണ്ടായ അതേ നിരാശ Play Store റിവ്യൂ ബോക്സിലും പ്രതിഭലിച്ചു. 4.7 റേറ്റിങ് ഉണ്ടായിരുന്ന ആപ്പ് 3.8 ലേക്ക് കൂപ്പുകുത്തി.

പിന്നെ ഗൂഗിൾ തപ്പി offline mode ഉണ്ടായിരുന്ന അവസാനത്തെ bug-free വേർഷൻ ആയ 4.2.8 ഇൻസ്റ്റാൾ ചെയ്തു. അബദ്ധത്തിൽ പോലും പ്ലേ സ്റ്റോറിൽ നിന്നും update ആവാതിരിക്കാൻ ശ്രദ്ധിച്ചു സൂക്ഷിച്ചു.

അപ്പോളും പുതിയ വേർഷനിൽ എന്നെങ്കിലും offline mode add ചെയ്യും എന്ന് പ്രതീക്ഷിച്ചു കാത്തിരുന്നു. ഒരു വർഷക്കാലം ഒന്നും ഉണ്ടായില്ല.

അവസാനം, fans ന്റെ നിരന്തര അഭ്യർത്ഥന പ്രകാരം Appsomaniacs തന്നെ Mini Militia Classic എന്ന പേരിൽ പഴയ ആപ്പ് കുറച്ചു നല്ല modifications ഓടെ 2020 ഡിസംബറിൽ അവതരിപ്പിച്ചു!

നിലവിൽ Early access ആണ്. Alpha വേർഷൻ.
കഴിഞ്ഞ ആഴ്ച (July 28ന്) വന്ന update ഓടു കൂടി bug free ആയിട്ടുണ്ട്. Yes, it is back 🔥

Online ൽ 12 പേർക്ക് ആണ് ഒരുമിച്ചു കളിക്കാൻ കഴിയുക.
Play online ൽ Custom game ൽ ഒരാൾ ഏതെങ്കിലും ഒരു server സെലക്ട് ചെയ്ത് room create ചെയ്യുക. മറ്റുള്ളവർ അതിൽ ജോയിൻ ചെയ്യുക.


ലൈവ് വോയ്‌സ് ചാറ്റിന് പാരലൽ ആയിട്ട് ടെലിഗ്രാം ഗ്രൂപ്പ്‌ create ചെയ്യാവുന്നതാണ്. 👌
ടെലിഗ്രാം വോയ്‌സ് ചാറ്റിന്റെ floating icon വഴി live ആയോ PTT ആയോ സംസാരിക്കാം.
